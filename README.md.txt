# 🏫 School Management System - نظام إدارة المدرسة

مشروع تطبيق ويب خفيف وتفاعلي لـ **إدارة بيانات الطلاب والإحصائيات المدرسية**.

## 🌟 الميزات (Features)
- 📊 **لوحة إحصائيات:** عرض إجمالي عدد الطلاب والمعلمين والفصول.
- ➕ **إضافة طالب جديد:** نموذج مدعوم بالتحقق من البيانات (Form Validation).
- 🗑️ **حذف وإدارة الطلاب:** تحديث الجدول والإحصائيات ديناميكياً باستخدام JavaScript.
- 📱 **تصميم متجاوب:** يعمل بمرونة على كافة الشاشات (Responsive Design).

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **HTML5** - بناء هيكل الصفحات
- **CSS3** - التنسيق والتصميم العصري (Flexbox & Grid)
- **JavaScript (ES6)** - البرمجة التفاعلية وإدارة البيانات
